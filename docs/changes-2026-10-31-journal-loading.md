# Журналы и загрузка карточек

- В задачах кнопка создания расположена рядом с заголовком. Убраны внешние рамки фильтров и групповых действий; поля и действия сохранены.
- Период договоров начинается отдельной строкой во всех трёх темах.
- Поле заказчика в карточке договора отрисовывает только выбранную запись и использует существующий механизм удалённого поиска (до 30 результатов). Валидация выбранного заказчика остаётся серверной. Поисковый endpoint требует вход и право просмотра заказчиков.
- Количество договоров для журнала заказчиков считается отдельной группировкой по customer_id, без группировки полей заказчиков. Упрощён шаблон строк, URL и параметры возврата вычисляются однократно. Непрерывный список, сортировка, фильтрация и итоги сохранены.

Проверка: тесты карточек, журнала заказчиков, задач, справочников и удалённого выбора; Chromium проверка расположения элементов во всех трёх темах. Синтетический замер отрисовки строк 3000 заказчиков: медиана трёх прогонов 0,276 с до изменений и 0,138 с после; одинаковый размер HTML. Это не измерение полной загрузки страницы на рабочем VPS.

Миграций БД нет. Изменения применяются обычным обновлением CRM.
