# Заказчики, справочники и распознавание — 24.10.2026

## Новый заказчик из договора

В карточке нового и существующего договора под полем «Заказчик» появилась кнопка «+ Новый заказчик». Форма открывается отдельным окном поверх договора. Заполненные поля договора при этом сохраняются в браузере. После создания заказчик сразу выбирается в договоре; сам договор сохраняется своей кнопкой отдельно.

Тип заказчика:

- **Физическое лицо:** ФИО, контакты, адрес, паспорт. Кнопка «Загрузить паспорт» заполняет поля для проверки перед сохранением.
- **Юридическое лицо:** наименование организации, ИНН, КПП, ОГРН, юридический адрес, банк, БИК, расчётный и корреспондентский счета, представитель и основание полномочий, контакты. Паспортные поля физлица скрываются. Числовые реквизиты проверяются по допустимой длине; проверка по реестрам не выполняется.

Тип и ИНН видны также в справочнике заказчиков. Импорт онлайн-заявок продолжает искать физических лиц и не связывает туриста с организацией только из-за общего телефона.

## Значения по умолчанию

В справочниках стран, городов вылета, валют, туроператоров, типов договоров, способов оплаты, питания, трансферов, страховок и топливных сборов добавлена редактируемая колонка «По умолчанию». Такая же отметка есть в списках заказчиков и туристов, используемых для выбора связанных записей.

Поставьте галочку у нужной записи и нажмите «Сохранить» внизу списка. В каждом справочнике может быть одна отмеченная запись. Выбор новой снимает прежнюю отметку. Ограничение дополнительно контролируется базой данных.

Настройки применяются к новым незаполненным формам, включая обычные формы управления и строки финансов/стоимости. Существующие документы, импортированные значения и введённые значения при ошибке сохранения не заменяются. Для валюты при обновлении сохраняется прежнее начальное поведение RUB; можно выбрать другую валюту галочкой.

## Распознавание паспортов

Исправлен случай, когда загранпаспорт заказчика всегда давал пустой результат. Добавлено отдельное чтение латинской машиночитаемой зоны: смешанный русский/английский режим мог распознавать её как кириллицу. Допускаются пробелы, пустые строки между строками и отсутствующие завершающие заполнители; номера и даты по-прежнему требуют контрольных цифр.

Обработка теперь включает несколько проходов, контрастирование, нижнюю часть страницы и повороты. Общий бюджет OCR — 42 секунды. Если отсутствует русский языковой пакет, выводится сообщение об установке, а не рекомендация переснять фото.

После обработки можно раскрыть «Распознанный текст». Это помогает отличить ошибку чтения букв от ошибки выделения конкретных полей. Текст передаётся только авторизованному пользователю и не записывается в БД. Фотографии обрабатываются локально и удаляются из временного каталога. Результат распознавания пользователь проверяет до сохранения. Для заказчика можно указать вид документа: паспорт РФ или загранпаспорт.

Проверено на искусственных изображениях с русскими полями и стандартной тестовой MRZ, включая поворот. Реальные фотографии пользователя в среду разработки пока не предоставлены, поэтому точность на них не подтверждена.

## Установка на VPS

В терминале Mac подключиться к серверу:

```bash
ssh -o ObscureKeystrokeTiming=no root@168.113.171.231
```

Далее на сервере по одной команде:

```bash
git -C /opt/aborigen-crm pull --ff-only origin main
```

```bash
bash /opt/aborigen-crm/deploy/install-service.sh
```

Это обновление не требует новых Python-пакетов или дополнительных ключей. Если появится сообщение об отсутствии русского языка, один раз выполните `bash /opt/aborigen-crm/deploy/install-ocr.sh`. После установки обновите страницу браузера.
