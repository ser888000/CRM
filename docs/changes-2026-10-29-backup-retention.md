# Ограничение резервных копий и очистка переноса

Перед созданием следующей копии обновления/паспортов/переноса удаляются более старые копии. Сохраняется последняя существующая; если она повреждена, также сохраняется последняя проверенная непустая SQLite-база с таблицами. Если проверенных копий нет, ничего не удаляется. После успешного создания остаются предыдущая и новая копии. Новые копии обновлений/паспортов публикуются после проверки через временный файл, ошибки не уничтожают предыдущую копию.

Установщик при вызове обновлялкой использует её проверенную копию, без второго дублирующего снимка. При самостоятельном вызове установщик создаёт собственную копию с той же политикой хранения. Общий модуль сохраняется в /usr/local/libexec, чтобы откат репозитория не ломал импорт обновлялки.

Однократная очистка на сервере после обновления:

```sh
python3 /opt/aborigen-crm/deploy/cleanup-storage.py
df -h /
```

Она сокращает архивы обновлений и паспортов по указанным правилам и удаляет каталоги завершённых/неуспешных переносов старой CRM. Загруженные данные, библиотека, записи импорта и исходные записи, сохранённые в БД, не меняются. Ожидающие/выполняющиеся переносы и незавершённые обновления защищены блокировками; при активном режиме обслуживания очистка отменяется. Файлы блокировок сохраняют владельца каталога приложения. Статус завершённого переноса после удаления его файлов больше не показывается; отчёт и источники доступны из записей импорта в БД.

Удалённая очистка в этой сессии не выполнялась: SSH из рабочей среды недоступен. Команду запускает пользователь в существующем подключении к серверу. Неизвестные имена копий и символические ссылки не удаляются.
