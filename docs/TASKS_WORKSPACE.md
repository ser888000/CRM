# Раздел «Задачи»

Открывается через левое меню «Задачи».

## Список

- Быстрые даты «Сегодня» и «Завтра» показывают оба статуса. Произвольные даты задаются полями «Срок с / по». Статусы «Все», «Запланировано», «Выполнено» применяются в выбранном периоде.
- Кнопка «Просрочено» в строке статусов показывает все невыполненные задачи с прошедшим сроком независимо от диапазона дат и статуса. Остальные фильтры сохраняются.
- Поиск по названию/описанию/номеру брони, заказчику, туроператору и сотруднику. Русские буквы сравниваются без регистра. Отдельно выбираются общие задачи.
- У каждой колонки есть сортировка и фильтр с выбором нескольких значений, как в договорах.
- Фильтры, период и страница сохраняются в пользовательской сессии. «Сбросить» возвращает исходное представление «Сегодня».
- На странице до 100 задач, чтобы большой журнал не перегружал браузер. «Выбрать все» относится к показанной странице.
- Просроченные сроки выделены; описание раскрывается в строке. Видны заказчик, договор, ТО, брони и сотрудник. Переход к брони доступен при настроенном шаблоне ссылки у ТО.

## Действия

Нажатие на статус отмечает задачу выполненной или возвращает в запланированные. Для нескольких задач выберите галочки и действие над таблицей. Доступны выполнение, возврат в запланированные перенос на дату и отдельная кнопка «Перенести на завтра». Выполненные задачи при переносе пропускаются, без изменения их срока. Результат действия показывает количество изменённых записей.

Все изменения статуса и срока записываются в историю с пользователем, прежним и новым значением. Список доступен с правом view_task, действия — с change_task.

## Создание и редактирование

«+ Новая задача» открывает форму в основном интерфейсе CRM. Нажатие на название существующей задачи открывает редактирование. Есть тип из справочника «Справочники и управление → Типы задач», своё название, описание, срок, необязательные заказчик и договор, ТО и номер брони для отдельной задачи, сотрудник и статус.

Если договор указан, заказчик и ТО определяются по нему; явно выбранный другой заказчик вызывает ошибку. Задачи, созданные по шаблону договора, закреплены за своим договором. Им можно менять срок, описание, сотрудника и статус. Это сохраняет корректность последующих сверок с Турвизором.

При создании можно выбрать повтор каждый день, неделю, месяц или год и общее число задач (до 366 с учётом первой). Вся серия создаётся сразу; следующие задачи не зависят от выполнения предыдущей. Если месяц короче исходной даты, используется его последний день. Переход за допустимые даты отменяет всю серию, включая первую задачу.

Редактирование защищено от перезаписи изменений другого окна. Возврат в список сохраняет его фильтры и страницу. Уведомления в Telegram в этот пакет не входят.

## Обновление

```bash
ssh -o ObscureKeystrokeTiming=no root@168.113.171.231
```

На сервере по одной команде:

```bash
git -C /opt/aborigen-crm pull --ff-only origin main
```

```bash
bash /opt/aborigen-crm/deploy/install-service.sh
```

После завершения обновите страницу CRM. Установщик применит миграции и заполнит типы задач существующими названиями. В справочнике можно сократить название и задать описание для новых задач. Связанные задачи сразу показывают актуальное название типа. Сроки и правила автоматического создания остаются в «Шаблонах задач», где выбирается тип.


## Порядок фильтров и договорные типы задач

Первая строка: Сегодня, Завтра, Даты с/по, Применить, Сбросить. Вторая: Задача/описание/бронь, Заказчик, Туроператор, Сотрудник. Ниже: Все, Запланировано, Выполнено, Просрочено. Просроченные невыполненные задачи отбираются независимо от дат; переход на другой статус снова использует выбранные даты.

В «Типах задач» добавлена редактируемая галочка «Задачи по договору». Только отмеченные типы появляются в договоре в разделе «Задачи по договору»: каждая строка содержит выбор задачи и её срок. Типы, для которых задачи уже созданы в этом договоре, не предлагаются повторно. Снятие галочки не удаляет существующие задачи.

Дата рассчитывается по связанному шаблону; у типа без шаблона берётся дата договора. Дату можно изменить перед сохранением. Описание берётся из типа; для шаблона проверки вылета также добавляются рейсы. При обновлении ранее активные шаблоны сохраняют участие в договорном списке; галочки можно настроить самостоятельно.

Обычный и групповой импорт Tourvisor продолжают использовать прежние четыре активных шаблона, независимо от галочки «Задачи по договору». Новая настройка относится к ручному выбору задач в карточке договора и её административной форме.
