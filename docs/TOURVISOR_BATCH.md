# Групповая загрузка новых договоров из Турвизора

## Где открыть

«Договоры → Групповая загрузка» или «Импорт Турвизора → Групповая загрузка новых договоров». Поштучная загрузка и сверка остаются на прежней странице.

## Работа

1. Получите последние 25, 50 или 100 **онлайн-заявок**. Необязательный фильтр ID соответствует параметру API `lastid`: заявки новее указанного ID. Экспорт обращений `orders.php` не используется.
2. Список показывает новые заявки, уже загруженные договоры, договоры с изменениями и ошибки. Это ограниченная порция API, а не гарантия полной истории. Не все онлайн-заявки обязательно уже забронированы у ТО: выбирайте договоры, которые готовы переносить в CRM.
3. Отметьте новые заявки или нажмите «Выбрать все новые». Проверьте дату окончания тура, заказчика, список туристов, проживание и стоимость. При неоднозначном совпадении заказчика выберите существующего или создание нового. Без выбора такой договор не запустится.
4. Выберите шаблоны задач для пакета. В подробностях каждой заявки можно изменить сроки. Пустой срок будет рассчитан по шаблону от даты договора/начала/подтверждённого окончания тура; выбранные сроки фиксируются перед запуском.
5. Нажмите «Импортировать выбранные новые договоры». Очередь обрабатывает по одной заявке и показывает результат каждой строки. «Пауза» прекращает отправку следующих запросов после завершения текущего. Страницу можно закрыть: фоновый импорт без браузера не выполняется. Откройте недавний список и нажмите «Продолжить загрузку».
6. После завершения откройте итог. Для ошибочных и невыбранных новых заявок можно исправить выбор заказчика/даты/задач и запустить выбранные строки снова. Изменения самой заявки в Турвизоре требуют нового запроса списка.

Существующие договоры не обновляются пакетно: используйте «Сверить поштучно». Платежи и себестоимость из Турвизора не загружаются.

## Сохранность

- Каждая заявка создаётся в своей транзакции; её ошибка не откатывает уже созданные договоры.
- ID Турвизора остаётся уникальным. Если договор появился после предпросмотра или предыдущий запрос завершился при обрыве связи, повторный шаг отмечает существующий договор без его изменения.
- Применяется прежняя проверка совпадений заказчиков. Несколько договоров одного заказчика могут использовать одну карточку. Если во время очереди появилось неоднозначное совпадение, эта строка завершится ошибкой для ручного выбора, а следующие продолжат загружаться.
- Предпросмотр принадлежит создавшему его пользователю, требует прав импорта и действует 30 минут. После истечения срока загрузите новый список. Успешные строки сразу очищают временную исходную копию; договор хранит обычные импортированные данные.
- Установщик включает ежечасную очистку устаревших снимков (с задержкой до пяти минут). Техническая история пакета удаляется спустя семь дней; сами договоры не удаляются.

## API и проверка

Используются документированные параметры `ordersonline.php`: `format=json`, `limit`, `lastid`. Форматы дат или постраничные параметры, не описанные в предоставленной документации, не добавляются. Живой запрос из среды разработки подтвердил получение 25 записей; персональные данные ответа не выводились и не сохранялись в репозиторий. Из тестовой среды реальные договоры в рабочей CRM не создавались.

Проверены тестами отдельные ошибки, повторы, одновременное появление договора после предпросмотра, выбор заказчика, даты/задачи, доступ другого пользователя, CSRF и истечение предпросмотра. Браузерная проверка выполнена на искусственных заявках.

## Установка

Подключитесь к VPS:

```bash
ssh -o ObscureKeystrokeTiming=no root@168.113.171.231
```

Затем по одной команде:

```bash
git -C /opt/aborigen-crm pull --ff-only origin main
```

```bash
bash /opt/aborigen-crm/deploy/install-service.sh
```

Скрипт применяет миграции и устанавливает `aborigen-crm-cleanup.timer`. Проверка очистки: `systemctl status aborigen-crm-cleanup.timer --no-pager`. Ручная очистка: `systemctl start aborigen-crm-cleanup.service`. Служба использует существующий файл окружения, включая путь к активной базе. API-ключ повторно вводить не нужно.
