# Поля онлайн-заявки Tourvisor

Структура получена из реального ответа API. Все непустые значения в JSON заменены вымышленными примерами; это не данные поездки. Названия полей, вложенность, типы значений и количество элементов сохранены. Пустые значения оставлены пустыми.

[Открыть JSON](https://github.com/ser888000/CRM/blob/main/docs/examples/tourvisor-online-anonymized.json)

## Туристы (2 записи)

Массив tourist. Ниже поля одной записи.

| Поле API | Смысл |
| ----- | ----- |
| tourist\[\].passportseries | Серия паспорта |
| tourist\[\].passportnumber | Номер паспорта |
| tourist\[\].passportissuedate | Дата выдачи паспорта |
| tourist\[\].passportenddate | Срок действия паспорта |
| tourist\[\].passportissuedby | Кем выдан паспорт |
| tourist\[\].passporttype | Тип паспорта: 0 — загранпаспорт, 1 — российский |
| tourist\[\].surname | Фамилия туриста по паспорту |
| tourist\[\].name | Имя туриста по паспорту |
| tourist\[\].gender | Пол |
| tourist\[\].birthdate | Дата рождения |
| tourist\[\].birthcountry | Страна рождения |
| tourist\[\].nationality | Гражданство |
| tourist\[\].isclient | Признак, что турист является заказчиком; требуется проверка сопоставления |

## Перелёты (2 записи- не факт, может быть и больше если с пересадками)

Массив transport. Ниже поля одной записи. \- это копируем из турвизора, но если будем вводить вручную, то это сложный ввод, давай ниже просто сделаем общее текстовое поле, куда мы будем копировать перелеты от туроператоров сразу двумя и более строчками

| Поле API | Смысл |
| ----- | ----- |
| transport\[\].direction | Направление: 1 — туда, 2 — обратно |
| transport\[\].number | Номер рейса |
| transport\[\].datefrom | Дата вылета |
| transport\[\].dateto | Дата прилёта |
| transport\[\].timefrom | Время вылета |
| transport\[\].timeto | Время прилёта |
| transport\[\].aircompany | Авиакомпания |
| transport\[\].plane | Самолёт |
| transport\[\].terminalfrom | Аэропорт/терминал вылета |
| transport\[\].terminalto | Аэропорт/терминал прилёта |
| transport\[\].terminalcodefrom | Код аэропорта вылета |
| transport\[\].terminalcodeto | Код аэропорта прилёта |
