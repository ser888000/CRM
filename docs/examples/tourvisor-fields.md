# Поля онлайн-заявки Tourvisor

Структура получена из реального ответа API. Все непустые значения в JSON заменены вымышленными примерами; это не данные поездки. Названия полей, вложенность, типы значений и количество элементов сохранены. Пустые значения оставлены пустыми.

[Открыть JSON](tourvisor-online-anonymized.json)

| `comments` | Комментарий |

## Что отсутствует в этом ответе

Отдельные поля номера и даты договора, номера броней ТО, платежи, возвраты и себестоимость. По уточнению пользователя, в его процессе `id` и `date` используются как номер и дата договора. Дата окончания тура отдельным полем не передана: её нужно определить по данным поездки и подтвердить.

Можно прислать решения в формате: `hotel[].room → импортировать в «Категория номера»`; `manual → не импортировать`. Колонки журнала договоров, поля карточки и строки туристов — разные места отображения, укажите желаемое место при необходимости.
