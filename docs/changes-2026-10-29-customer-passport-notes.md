# Паспортные данные заказчиков из примечаний

Раздел «Справочники и настройки → Паспорта из примечаний», доступен только администратору: `/management/customer-passports/`.

GET не меняет данные. POST с CSRF сначала создаёт полную SQLite-копию через Backup API в каталоге `customer-passport-backups` рядом с активной базой (права каталога 0700, файла 0600), проверяет `quick_check`. Если копия не создана или проверка не прошла, заполнение не начинается. Ссылка на скачивание копии доступна только администратору и подписана сервером. Копия сохраняется на сервере также после ухода со страницы.

Распознаётся одна полная строка с датой рождения, отметкой «г.р.», паспортом РФ (серия 4 цифры, номер 6), датой выдачи, названием органа и кодом подразделения. Неоднозначные, неполные, конфликтующие записи и карточки с загранпаспортом/организации остаются без изменений. Автоматически заполняются только пустые поля; примечания сохраняются. Обновление всех карточек и аудит выполняются в одной транзакции, повторный запуск идемпотентен. Аудит содержит названия полей, без паспортных значений.

Рабочая база удалённо не обработана: SSH-соединение с сервером отклоняется. После установки обновления запустить обработку в разделе управления. На локальном снимке распознано 74 полных строки; 327 примечаний с упоминанием паспорта оставлены для проверки. Это статистика снимка, не результат обработки рабочей базы.

## Диагностика ошибки запуска

Общее сообщение заменено указанием этапа и безопасным кодом ошибки. Сообщения не включают SQL, пути и содержимое карточек. Ошибки Django DatabaseError также обрабатываются после отката транзакции. Если копия создана, а заполнение отменено, ссылка на скачивание копии сохраняется в ответе.

11 целевых тестов прошли, включая отказ доступа к файлам и отмену записи при ошибке аудита. Полный запуск на временном клоне локального снимка создал копию и обновил 71 карточку. Причина ошибки рабочей среды пока не подтверждена; требуется сообщение обновлённого обработчика с сервера.

## Дата рождения без пометки и ФИО перед датой

Пометка «г.р.» после даты рождения теперь необязательна. Допускается ФИО перед датой; ФИО из примечания не переносится в имя карточки. Дата рождения по-прежнему обязательна для распознавания этого формата. Несколько паспортов, противоречия с заполненными полями и некорректные даты не обрабатываются автоматически.

На том же локальном снимке распознаётся 244 строки вместо 74; для проверки остаётся 157 упоминаний паспорта. Рабочую базу для повторного прохода нужно обработать через прежнюю кнопку после обновления. 14 целевых тестов прошли, включая новый формат, сохранение имени и повторный запуск без изменений.
