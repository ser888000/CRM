## Исправления сверки и ссылки ТО — 23.10.2026

- Префикс ссылки ТО, оканчивающийся на `=` или `/`, допускается без ручного `{booking}`: номер брони добавляется в конец. Полный HTTP(S)-адрес обязателен. Явная подстановка `{booking}` по-прежнему поддерживается.
- Проживание сравнивается один раз: в первом отеле используются текущие редактируемые значения договора, дубли строк из зеркальных полей удалены.
- Услуги: в колонке поля только «Название». Неизменённые услуги сопоставляются точно; похожие переименованные — по названию. Удалённая услуга показывается отдельно с пустым новым значением. Без стабильных ID полностью непохожие названия могут отображаться как удаление и добавление.
- Числовое сравнение Decimal не считает разное количество нулей после запятой изменением стоимости.

## 24.10 — завершение карточки договора

Добавлена шестая плашка «Процент комиссии»: (сумма договора − себестоимость) / сумма договора × 100, два знака после запятой. При нулевой сумме выводится «—». Показатель доступен с правом просмотра финансов.

Вкладка заказчика использует общую сетку из трёх колонок на широком экране, с теми же адаптивными переходами на две/одну колонку, что и остальные вкладки. «Паспортные данные» переименованы в «Примечание» без изменения содержимого; адрес регистрации перенесён непосредственно перед примечанием.

ФИО туриста расположено после фамилии и имени по паспорту и автоматически составляется из них в браузере и на сервере. Поддержка действует также в справочнике туристов; прежние записи с одним полным именем не теряются.
