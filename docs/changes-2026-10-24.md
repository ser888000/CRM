# Изменения CRM — 24 октября 2026

## Журнал договоров — главная страница

- Первая строка поиска: заказчик, e-mail, телефон. Поиск ФИО не зависит от регистра, включая русские буквы. Телефон можно искать с +7, 7, 8 и без форматирования.
- Даты вынесены во вторую строку. «Сегодня» и «Месяц (текущий)» фильтруют по дате договора по московскому времени.
- Нажатие на название колонки сортирует по возрастанию/убыванию. Кнопка ▾ открывает выбор одного или нескольких значений с поиском внутри списка. Фильтры разных колонок сочетаются; значения одной колонки объединяются по принципу «или».
- Дополнительные колонки: способ оплаты, примечание, город вылета, дата оплаты ТО, Взр, Дети. Их можно скрыть и перетащить в нужном порядке.
- ИТОГО осталось внизу таблицы: количество договоров и суммы по выбранным фильтрам. Дублирующая строка над таблицей убрана.

## Карточка договора

- В «Обзор и тур» валюта нового предложения — RUB. Примечание находится последним в «Основное». Рейсы идут первыми в «Услуги и перелёты». Ссылка называется «Ссылка на тур у ТО».
- Питание, трансфер, страховка и новый «Топливный сбор» — текстовые поля с подсказками из справочников. Можно вводить собственные значения. Управление справочниками — в «Справочники и настройки». При обновлении туда переносятся существующие значения соответствующих полей и добавляются стартовые варианты.
- Блок выбора задач в обзоре скрыт, если все шаблоны уже использованы или их нет. Существующие задачи доступны во вкладке «Задачи».
- В «Заказчик» ФИО автоматически собирается из фамилии, имени и отчества. Эти данные проверяются и на сервере. ФИО следует после отчества. Основной и дополнительные телефоны стоят в одной строке, e-mail — в следующей. Многострочные поля уменьшены до трёх строк.
- В «Туристы и стоимость» данные туриста раскрываются по нажатию на его имя. Отдельное раскрытие изменения строки стоимости сохранено.
- В «Финансы» операция раскрывается по нажатию на её название. Для новой операции валюта оплаты ТО по умолчанию RUB.
- Автосборка ФИО работает и в справочнике заказчиков Django admin.

## Проверка заказчика при импорте

Перед созданием нового договора сравниваются ФИО, телефоны и e-mail заказчика. Телефоны нормализуются, e-mail и ФИО сравниваются без регистра. Для автоматического совпадения нужны одинаковое ФИО и хотя бы один совпадающий контакт; если другие указанные контакты противоречат друг другу, автоматической привязки нет.

При единственном надёжном совпадении предлагается существующий заказчик. При неоднозначности нужно выбрать похожего заказчика или «Создать нового». Выбор повторно проверяется перед сохранением. При использовании существующей карточки её данные не перезаписываются. Уже существующие дубликаты автоматически не объединяются.

## Загрузка паспорта

Кнопка «Загрузить паспорт» находится во вкладке заказчика и в форме каждого туриста, включая нового. Принимаются JPEG/PNG до 6 МБ и 16 мегапикселей. HEIC и PDF пока не поддерживаются.

Tesseract работает локально на VPS, фотографии не отправляются сторонним сервисам. Временный файл удаляется после обработки. Распознанные значения сначала предлагаются для заполнения формы, затем пользователь проверяет их и сохраняет обычной кнопкой. В базу фотографии не записываются.

Поддерживаются подписанные поля паспорта РФ и машиночитаемая зона загранпаспорта TD3. Для номера и дат TD3 проверяются контрольные цифры. На фотографиях с бликами, искажениями и нестандартным расположением полей результат может быть неполным — оставшиеся значения нужно ввести вручную. Проверка перед сохранением обязательна. На VPS с 1 ГБ памяти обработка ограничена одним паспортом за раз в стандартной конфигурации с одним worker.

## Установка обновления на VPS

В SSH-терминале сервера, от root, по одной команде:

```bash
git -C /opt/aborigen-crm pull --ff-only origin main
```

```bash
bash /opt/aborigen-crm/deploy/install-service.sh
```

Однократно для распознавания:

```bash
bash /opt/aborigen-crm/deploy/install-ocr.sh
```

Обычный установщик обновляет Python-зависимости и применяет миграции с резервной копией базы. Установщик OCR добавляет Tesseract и языки rus/eng. После обновления перезагрузите страницу браузера. Настройки HTTPS и API-ключ сохраняются.
